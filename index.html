操作

「NDI出力用の別ウィンドウを開く」は、映像だけを映した小さな別ウィンドウを 開きます。これを NDI Screen Capture（無料・別途インストール）で キャプチャしてNDIソースとして配信すると、Resolumeの「Sources」タブに 自動的に現れ、VirtualDJのNDI出力と同じ感覚でVJレイヤーとして使えます。 詳しい手順は「使い方・注意点」タブをご覧ください。

スキャン対象フォルダ（内部フォルダ・外部VJ用ドライブ等）

          

            外部ドライブ（VJ用のE:ドライブなど）を追加するときは、ドライブの
            一番上の階層（E:\ そのもの）ではなく、その中のフォルダ
            （例: E:\Anime）を選んでください。中に何もフォルダが無ければ、
            先にエクスプローラーでフォルダを1つ作ってから選んでください。
          

          
    
          
    
            
            
          
    
        
    

        
    
          
    ライブラリ構築
    
          
    
            
            
          
    
          
    
            
            
            
          
    
          
    
            「中断」は押した時点でログにすぐ反映されます。ただし処理中の1ファイルの
            解析（デコード等）は途中で止めることができないため、実際に停止するのは
            そのファイルの処理が一段落してからになります。1ファイルあたりの解析上限
            秒数を短めに設定しておくと、この待ち時間も短くなります。
          
    
          
    
        
    

        
    
          
    ブラウザ版からのライブラリ移行
    
          
    
            旧ブラウザ版（anisong_vj_web.html）の「設定」タブでエクスポートした
            NDJSONファイルを読み込み、曲データ・音響指紋をこのデスクトップ版へ
            インポートします（再スキャン不要）。インポート中、エクスポート元の
            フォルダ名ごとに、対応するフォルダの選択を求められます。

    認識パラメータ
    
      
    
        
        
        
        
        
        
        
        
        
        
        
        
        
        
      
    
      
    
        「曲切り替え検知ウィンドウ長」は、周囲の曲が別の曲に変わったことを素早く
        検知するために使う短い区間の長さです。短くするほど切り替えが早くなりますが、
        短すぎると誤検出が増える場合があります。「曲切り替え検知の間隔」は、この
        短い区間の解析をどれくらいの頻度で行うかです（照合間隔とは別に、これ専用に
        独立して動きます）。短くするほど切り替わりが早く反映されますが、PCの負荷は
        上がります。
      
    
      
    
        
      
    
    
    

    
    
      
    無音検出（画面を黒くする）
    
      
    
        
        
        
        
      
    
      
    
        マイクの音量がしきい値を下回っている状態が続いた時間を無音として計測します。
        周囲が完全に無音でなくても常に小さな環境音を拾ってしまい黒画面にならない
        場合はしきい値を上げ、逆に小さな物音で黒画面が解除されすぎる場合は
        しきい値を下げてください。
      
    
      
    
        設定の保存は上の「認識パラメータ」欄の「設定を保存」ボタンで、この欄も
        まとめて保存されます。
      
    
    
    

    
    
      
    データ管理
    
      
    
        
      
    
    
    
  
    

  
  
    
    
    
      
    これは何か
    
      
    
        マイクで周囲に流れているアニソンを聞き取り、あらかじめ指定したフォルダ
        （内部ストレージ・外部VJ用ドライブなど）にあるアニメ映像(mp4/webm等)の中から
        音声が一致するものを自動的に探し出し、再生位置を合わせながら再生します。
        すべてこのPC上だけで完結し、外部の音楽認識サービスやサーバーには一切
        接続しません（完全オフラインの自作音響指紋方式）。曲データ・音響指紋は
        このPC内のファイル（SQLite）に保存され、曲数が増えてもメモリ使用量が
        際限なく増えない設計になっています。
      
    
    
    
    
    
      
    使い方（初回のみ）
    
      
    
        1. 「認識・再生」タブの右側にある「ライブラリ」欄でフォルダを追加し、
        「ライブラリを構築 / 更新」を押します。すでにブラウザ版でライブラリを
        構築済みの場合は、代わりに「ブラウザ版からのライブラリ移行」欄から
        エクスポート済みNDJSONファイルをインポートすれば再スキャン不要です。
    
        2. 「設定」タブでマイクを選び、必要ならパラメータを調整して保存します。
    
        3. 「認識・再生」タブの左側で「▶ 開始」を押すと、マイク許可のダイアログが
        出ます。許可すると認識と自動再生が始まります。
    
        4. 動画プレビューを第2画面（プロジェクター等）にドラッグしてから「全画面表示」を押すと、
        VJ出力として使えます。
      
    
    
    

    
    
      
    2回目以降の起動について
    
      
    
        構築したライブラリ（曲の一覧・音響指紋データ）とフォルダの登録は、
        このPC内のアプリデータフォルダに自動的に保存されます。次回このアプリを
        開いたときにフォルダ選択やライブラリ構築をやり直す必要はありません。
        アプリを開くと保存されたライブラリが自動的に読み込まれるので、そのまま
        「▶ 開始」を押すだけで使えます（画面上部に読み込み件数の通知が出ます）。

    
        ライブラリの構築 / 更新が必要になるのは、新しい動画ファイルを
        追加したときだけです。その場合も、既に登録済みのファイルは自動的に
        スキップされ、新しく増えた分だけが解析されます。
      
    
    
    
    
    
      
    動作環境・注意点
    
      
    
        - Windows 11（24H2）向けのデスクトップアプリです。
    
        - 認識したライブラリ・設定はこのPC内にのみ保存されます。外部には一切
        送信されません。
    
        - 周囲雑音が大きい環境では認識の信頼度が下がります。雑音が音楽と同程度以上に
        大きい場合は、誤った曲を再生するより「安全側に倒して何も再生しない」ように
        意図的に設計しています。
    
        - ごく稀に、似た旋律が何度も出てくる楽曲では「曲は合っているが再生位置がずれる」
        ことがあります。気になる場合は設定の「連続一致で確定させる回数」を増やしてください。
    
        - 初回起動時、Windowsのマイクのプライバシー設定でこのアプリへのマイクアクセスを
        許可する必要がある場合があります。「▶ 開始」を押しても音が拾えない場合は、
        Windowsの設定「プライバシーとセキュリティ」→「マイク」を確認してください。
      
    
    
    

    
    
      
    Resolumeへ NDI で映像出力する（VirtualDJと同じ運用にする）
    
      
    
        本ツール自体がVirtualDJのように「内蔵のNDI出力」を持つことはできませんが、
        無料のNDI Screen Capture（NewTek/NDI公式ツール、Windows対応）を
        画面キャプチャの橋渡しとして使うことで、実用上ほぼ同じことが実現できます。
      
    
      
    
        手順
    
        1. 「認識・再生」タブの「🡵 NDI出力用の別ウィンドウを開く」を押します。
        映像だけを映した小さなウィンドウが別に開きます（元のプレビューはそのまま
        再生され続けます）。このウィンドウを、キャプチャしやすい場所
        （例: 使っていないモニタや画面の隅）に置いておきます。
    
        2. NDI Tools（NDI Screen Capture を含む無料ツール集）
        をインストールします。
    
        3. NDI Screen Capture を起動し、キャプチャ対象として先ほどの
        「NDI出力ウィンドウ」を選択します（画面全体ではなく、そのウィンドウ／
        その領域だけを選ぶと余計なものが映り込みません）。配信名（NDIソース名）を
        分かりやすい名前（例: AnisongVJ）に設定します。
    
        4. Resolume の「Sources」タブを開きます。ネットワーク上にNDIソースが
        流れていれば自動的に一覧に現れるので、先ほどの名前のソースをレイヤー／
        クリップにドラッグして使います。
    
        5. もし一覧に出てこない場合は、両方のPCが同じネットワーク（同じルーター
        配下）にあるか、WindowsのファイアウォールがNDIの通信をブロックして
        いないかを確認してください。
      
    
      
    
        補足
    
        - より高度な合成（複数ソースの切り替え、クロップ、拡大縮小など）をしたい
        場合は、NDI Screen Captureの代わりに OBS Studio
        （ウィンドウキャプチャ）＋ obs-ndi プラグインを使う方法もあります。
        こちらの方が画質・柔軟性の面で有利なことがありますが、設定はやや複雑です。
    
        - 「NDI出力用の別ウィンドウ」の映像に動画自体の音声も乗せたい場合は、
        「設定」タブの「動画自体の音声もミュートせず再生する」をオンにしてください
        （通常はDJ側の音声がそのまま鳴っているため、オフのままで問題ありません）。
    
        - 頻繁なシーク（早送り／巻き戻し相当の操作）の直後などに、まれにこの
        ウィンドウの映像だけが一瞬固まったように見えることがあります。これを
        軽減するため、シークの直後や、映像が実際に止まっていると判定した場合には
        自動的に再接続するようにしていますが、それでも固まって戻らない場合は
        「🡵 NDI出力用の別ウィンドウを開く」をもう一度押すと、開いたままの状態で
        手動で再接続できます。
